# Oloráculo · ¿Quién levanta la Copa? 🏆

Single-page que muestra, de forma llamativa, las predicciones del **Mundial 2026** del oráculo *Oloráculo* (funciona como huele).

Incluye: trofeo 3D (WebGL), ranking de candidatos, reparto del título (donut), el cuadro de eliminatorias con resultados reales + proyección, sonido generado en vivo y descarga de la predicción como imagen.

Datos: snapshot del motor Monte Carlo (10.000 simulaciones) del **7 de julio de 2026**.

Publicada con GitHub Pages desde la rama `gh-pages`.

> El modelo 3D del trofeo es un asset de terceros y el trofeo de la FIFA es marca registrada; se usa con fines demostrativos.
